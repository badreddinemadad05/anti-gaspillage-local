\# Anti-Gaspillage Local (AGL)



\## Description



Anti-Gaspillage Local est un projet universitaire

qui vise à réduire le gaspillage alimentaire.



L'application permettra aux commerçants et aux

particuliers de proposer leurs surplus alimentaires.



Les utilisateurs pourront consulter les offres,

réserver des paniers et les récupérer sur place.
